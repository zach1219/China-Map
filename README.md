# 中国地图数据可视化工具

将你的统计数据快速渲染成各省颜色深浅不同的中国地图。

## 功能特性

- 🗺️ **中国地图展示**：完整展示中国各省份地图，每个省份标注名称
- 📝 **文本输入**：直接粘贴包含省份名称的文本，自动识别并统计频次
- 🎨 **自定义颜色**：支持自定义最小值和最大值的着色颜色
- 📊 **数据统计**：实时显示匹配总数、匹配省份数和频次排行
- 💾 **下载PNG**：支持将地图导出为PNG图片

## 使用方法

1. 在文本框中粘贴包含省份名称的文本
2. 系统自动识别省份名称并统计出现次数
3. 地图根据频次自动着色（出现次数越多，颜色越深）
4. 可通过颜色选择器自定义着色颜色

## 示例

在文本框中输入：

```
北京 上海 广东 广东 广东 北京 四川 四川 浙江 浙江 浙江 浙江
```

地图将自动显示：浙江（4次）颜色最深，广东（3次）次之，北京和四川（2次）再次，其他省份为默认颜色。

## 技术栈

- 纯 HTML / CSS / JavaScript
- 无外部依赖，单文件部署
- 基于 SVG 渲染地图
