# 中国地图数据可视化工具

📊 **在线体验**：[https://zach1219.github.io/China-Map/](https://zach1219.github.io/China-Map/)

## 功能特性

- 📝 **文本智能识别**：粘贴任意文本，自动识别省份全称（如「河北省」）和简称（如「河北」），统计频次
- 🗺️ **地图着色可视化**：按频次从浅到深渐变着色，深色区域文字自动反白
- 🎨 **自定义颜色**：可调整最低/最高频次颜色、省份边界颜色
- 📤 **多格式导出**：支持 SVG 矢量图（适合 PPT）、高清 PNG（2x/3x）、透明背景 PNG
- 🏷️ **智能标签**：默认仅显示有数据省份的简称，可选显示频次
- 🖱️ **交互操作**：鼠标悬停显示省份名称和出现次数

## 地图数据合规说明

本项目地图数据来源于 [DataV.GeoAtlas 地理小工具](https://datav.aliyun.com/portal/school/atlas/area_selector)，由阿里云 DataV 提供的中华人民共和国行政区划 GeoJSON 数据，符合以下规范：

1. **领土完整**：地图包含中国全部 34 个省级行政区（23 个省、5 个自治区、4 个直辖市、2 个特别行政区）
2. **南海诸岛**：包含南海诸岛（九段线/十段线）标注，以虚线形式展示
3. **国界完整**：地图外框线完整展示中国领土边界
4. **数据来源权威**：GeoJSON 数据基于国家行政区划标准，由阿里云 DataV 团队维护更新
5. **无外部依赖**：所有地图数据内嵌于 JS 文件中，离线可用，不依赖任何外部服务

> ⚠️ 本工具仅用于数据可视化展示，地图边界以官方发布为准。如需用于正式出版物，请参照[自然资源部标准地图服务](http://bzdt.mnr.gov.cn/)获取标准地图。

## 技术实现

- **零依赖**：纯 HTML + CSS + JavaScript，本地打开即用
- **SVG 渲染**：基于 SVG 矢量图形，无限缩放不失真
- **数据处理**：支持省份全名（湖北省）和简称（湖北）两种输入格式
- **颜色算法**：HSL 色彩空间渐变插值，W3C 亮度公式自动计算文字对比色

## 使用方法

1. 直接打开 `index.html` 文件
2. 在右侧文本框粘贴包含省份名称的文本（全称或简称均可）
3. 点击「开始分析」
4. 左侧地图自动着色，右侧显示统计结果
5. 可调整颜色配置，导出图片
